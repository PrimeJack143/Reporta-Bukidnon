# Reporta Bukidnon

A mobile application for reporting road hazards and community issues in Bukidnon. Built with React Native and Supabase.

## Features

* Photo evidence required for accurate reports.
* Automatic GPS coordinate and address capture.
* Secure database storage.
* Recent reports display with image previews and map links.
* Sound notifications for new reports.

## Tech Stack

* React Native (Expo)
* Supabase (Database and Storage)
* Google Maps Integration
